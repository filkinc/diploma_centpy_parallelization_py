## jax-centpy

---

> Высокопроизводительный решатель гиперболических законов сохранения на **центральных разностных схемах высокого разрешения**, реализованный на [JAX](https://github.com/google/jax) с единым кодом для **CPU и GPU**.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![Built with JAX](https://img.shields.io/badge/built%20with-JAX-orange)
![Backend](https://img.shields.io/badge/backend-CPU%20%7C%20GPU-green)
![Precision](https://img.shields.io/badge/precision-float64-lightgrey)

Библиотека — вычислительное ядро выпускной квалификационной работы **«Моделирование распространения ударной волны в газе с локальным энерговложением средствами библиотеки JAX»**. Реализует две центральные схемы 2-го порядка — полудискретную **SD2** (Курганова–Тадмора) и полностью дискретную **FD2** (Нессияху–Тадмора) — для уравнений Эйлера и модельных уравнений в 1D и 2D.

## About

---

В основе — физическая задача о прохождении **ударной волны через зону локального энерговложения**: область пониженной плотности, моделирующую подвод энергии в газ (параметр разрежения α). Чтобы выявить закономерности динамики волны, нужно не одно решение, а **серия расчётов** при разных α — параметрическое исследование. А это десятки запусков, и потому требуется **производительный решатель**.

Отсюда — цель работы: построить собственный высокопроизводительный комплекс на JAX, который:

- решает **модифицированную задачу Римана** о взаимодействии ударной волны с зоной энерговложения в 1D и 2D;
- использует **центральные схемы**, где потоки на гранях ячеек считаются **без решения задачи Римана и без матриц Якоби** (в отличие от схем годуновского типа) — это делает их простыми и быстрыми;
- работает из **единого кода** и на процессоре, и на видеокарте — за счёт JIT-компиляции JAX.

## Results

---

| Что показано | Результат |
|---|---|
| **Порядок аппроксимации** | подтверждён 2-й порядок на гладких решениях (1D — перенос синуса, 2D — изоэнтропический вихрь) |
| **Кросс-верификация** | хорошее согласие профилей с точным решением, библиотекой **centpy** и промышленным **JAX-FLUIDS** |
| **Ускорение 1D (GPU)** | **≈48×** быстрее centpy и **≈27×** быстрее собственной CPU-версии (J = 16384) |
| **Ускорение 2D (GPU)** | **90–100×** быстрее centpy, до **60×** быстрее своей CPU-версии, **2.5–6×** быстрее JAX-FLUIDS (сетка 512×512) |
| **Масштаб** | досчитана задача на сетке **1024×1024** **|

Главный вывод: на GPU решатель быстрее аналогов в **десятки–сотни раз**, что делает параметрическое исследование по α практически осуществимым.

## Features

---

- Две схемы высокого разрешения 2-го порядка: **SD2** (Курганова–Тадмора) и **FD2** (Нессияху–Тадмора).
- Постановки **1D** и **2D** для системы уравнений Эйлера и модельных уравнений.
- Набор ограничителей наклонов: `minmod`, `superbee`, `monotonized_central` (MC), `van_leer`.
- Адаптивный шаг по времени по числу Куранта (CFL).
- Единый код **CPU/GPU**, JIT-компиляция через XLA, **двойная точность** (float64) по умолчанию.
- Готовые фабрики уравнений (Бюргерс, линейный перенос, Эйлер: взрыв, вихрь, Риман, Сод).

## Quick Start

---

```python
from jax_centpy import Solver1d, Pars1d, make_burgers_1d

# Параметры сетки и счёта
pars = Pars1d(
    x_init=0.0, x_final=1.0,
    t_final=0.2, dt_out=0.05,
    J=400, cfl=0.475, scheme="sd2",
)
eqn = make_burgers_1d(periodic=True)

solver = Solver1d(pars, eqn, scheme_name="sd2", limiter_name="minmod")
res = solver.solve()

res["x"]      # координатная сетка, (J,)
res["t"]      # моменты времени снапшотов
res["u_n"]    # состояния, (num_snapshots, J)
res["steps"]  # число шагов по времени
```

Двумерная задача — аналогично, через `Solver2d` / `Pars2d` и 2D-фабрики уравнений:

```python
from jax_centpy import Solver2d, Pars2d, make_euler_riemann_2d
```

## API

---

| Категория | Объекты |
|---|---|
| Параметры | `Pars1d`, `Pars2d` |
| Уравнение | `Equation1d`, `Equation2d` |
| Солверы | `Solver1d`, `Solver2d` |
| Схемы | `"sd2"`, `"fd2"` (аргумент `scheme_name`) |
| Ограничители | `"minmod"`, `"superbee"`, `"mc"`, `"van_leer"` (аргумент `limiter_name`) |

Своё уравнение задаётся через `Equation1d` (поля: `flux`, `spectral_radius`, `initial_data`, `boundary_handler`) — этого достаточно, чтобы решать произвольные одномерные законы сохранения.

## Numerical Methods

---

Обе схемы относятся к семейству **центральных разностных схем высокого разрешения** и не требуют решения задачи Римана или вычисления матриц Якоби.

- **SD2 — полудискретная схема Курганова–Тадмора.** Кусочно-линейная реконструкция с ограничителем minmod → численный поток типа Лакса–Фридрихса → пространственная дискретизация сводит задачу к системе ОДУ, которая интегрируется методом Рунге–Кутты 2-го порядка (SSP-RK2).
- **FD2 — полностью дискретная схема Нессияху–Тадмора.** Схема «предиктор–корректор» на шахматной сетке: полушаг по времени, затем коррекция на смещённой сетке.

Расчёты ведутся в двойной точности с адаптивным шагом по числу Куранта.
